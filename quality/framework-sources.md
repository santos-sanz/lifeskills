# Framework sources and adaptations

This repository uses established frameworks as practical prompts for AI agents. The skill text is an adaptation, not a replacement for the original works. No source is evidence for a claim merely because the framework is named.

## Negotiation and influence

- Chris Voss and Tahl Raz, *Never Split the Difference* (2016): tactical empathy, labels, mirrors, calibrated questions, accusation audits, and negotiation summaries. This repository adds explicit reciprocal-concession and authority checks.
- Robert B. Cialdini, *Influence: The Psychology of Persuasion*, 7th ed. (2021): influence principles including reciprocity, commitment and consistency, social proof, authority, liking, scarcity, and unity. This repository adds claim-to-evidence traceability, disclosure, consent, and anti-manipulation checks.

## Communication and execution

- Barbara Minto, *The Pyramid Principle* (1987; later editions): answer-first structure, grouped support, and logical ordering. This repository combines it with SCQA, evidence labels, owners, and decision triggers.
- George Mack's public writing on high agency: practical ownership, specific constraints, and action under uncertainty. The `high-agency` skill treats this as an execution lens, not clinical or scientific authority.
- Eiichiro Oda's *One Piece* character Monkey D. Luffy: the inspiration for the explicitly requested `luffy-mindset` style. It is motivational framing only and must not override factual or safety constraints.

## Strategy frameworks

- Igor Ansoff, “Strategies for Diversification,” *Harvard Business Review* (1957): the market/product growth directions adapted in the portfolio skill.
- BCG growth-share matrix: portfolio-growth logic associated with the Boston Consulting Group and Bruce Henderson's strategy work. The repository requires evidence and sensitivity rather than treating quadrants as automatic decisions.
- GE/McKinsey portfolio matrix: weighted industry-attractiveness and business-strength logic developed for portfolio planning. The repository requires explicit criteria, weights, normalization, and dependency checks.

## Attribution rule

When a pull request changes a named framework, preserve the source pointer, explain the adaptation, and avoid copying substantial source text. Framework labels never replace current evidence, professional advice, or user-specific judgment.
