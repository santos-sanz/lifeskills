# AI user-experience principles

## Calibrated trust
- Show what the system did, what it did not do, and how certain or incomplete the result is.
- Make verification proportional to consequence; high-risk outputs need stronger review cues.
- Avoid anthropomorphic language that implies intention, memory, authority, or emotion the tool does not have.

## User control
- Let users preview, edit, regenerate, undo, export, delete, and stop work where feasible.
- Keep important actions reversible and make irreversible consequences explicit before commitment.
- Preserve user agency when the system suggests, ranks, or automates an action.

## Useful transparency
- Explain data use, retention, cost, latency, sources, limitations, and human review at the decision point.
- Prefer a short explanation tied to the user's action over a generic “AI may make mistakes” disclaimer.
- Provide provenance or a verification path when an output is used to support a consequential decision.

## Inclusive utility
- Design for keyboard, screen-reader, contrast, localization, cognitive load, low bandwidth, and assistive technology.
- Keep error recovery understandable without requiring specialist model knowledge.
