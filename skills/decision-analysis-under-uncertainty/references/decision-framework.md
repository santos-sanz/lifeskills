# Decision framework

## Frame the decision
- Use one decision verb, one owner, one deadline, and one consequence of inaction.
- Include the status quo and a feasible fallback when they are meaningful alternatives.
- Define criteria before reviewing option scores to reduce motivated reasoning.

## Criteria discipline
- State each criterion in observable terms.
- Use units where a number has meaning and qualitative scales where it does not.
- Keep criteria independent enough to avoid double counting.
- Record the evidence and confidence behind each option score.

## Scenario discipline
- Base: most plausible combination of assumptions.
- Downside: adverse but plausible combination that could invalidate the choice.
- Upside: favorable case only when it changes the decision or investment size.
- Show which variable drives the largest change in recommendation.

## Sensitivity
- Re-run the comparison with the most uncertain weight or input changed.
- Prefer a robust option when small plausible changes reverse the ranking.
- If the decision is sensitive, make the uncertainty a next action rather than hiding it.
